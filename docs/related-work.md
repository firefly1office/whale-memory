# 思路从哪来，我们改了什么

whale-memory 借了不少别人的想法。这一页逐条写清楚：**借的是哪个想法、出处在哪、我们怎么改成了自己的，以及哪些是刻意不做的**。这里只借思路，没有复制任何项目的代码或文字。

核心约束先摆在前面，所有改造都绕着它们转：

1. `then` 写下就固定，`later` 只往后加——旧看法不被新看法覆盖。
2. 找不到就说找不到，不编。
3. 什么值得记、什么时候改口、要不要放下，由角色自己决定；系统不替她决定。

## 借来并改造的

| 我们的功能 | 借的想法 | 我们改了什么 |
| --- | --- | --- |
| **翻回那天的自己**（`asOf`，0.12） | Zep / Graphiti 的双时间轴：每条事实同时记"什么时候为真"和"系统什么时候知道"，可以重建任一时刻的知识状态。[Zep 论文](https://arxiv.org/abs/2501.13956) | 双时间轴回答的是"那时什么为真"；我们回答"**那时的她怎么想**"。截到某一刻，之后写下的后记、做的选择、被想起的次数全部看不见，原文本来就没变，所以不需要"失效"标记。 |
| **后来的感觉**（`revise --feeling`，0.12） | 自传记忆研究里的 fading affect bias：回想往事时感觉会变，而且主要不是记错了当时的感觉，是**现在的反应**不同了。[Frontiers 2025 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC12336169/) | 当时的感觉留在 `then.feeling` 里永远不动；后来的感觉作为后记的一部分追加。主流情感引擎（PAD 心情向量、按时间自动衰减，如 [affectus](https://github.com/n-yokomachi/affectus)）会自动把情绪拉回基线——**我们不做自动衰减**：淡没淡，由她自己说。 |
| **回想的出处**（`write --refs`，0.12） | Generative Agents 的 reflection：把多条观察归纳成更高层的想法，并保留指向依据的指针。[Park et al. 2023](https://arxiv.org/abs/2304.03442) | 论文自己承认，凭空归纳出的"反思"会被反复检索、越叠越偏。我们把出处变成**硬约束**：写入时校验每个引用的经历真实存在，找不到就整条拒绝；翻读时出处和"后来有哪些回想提到它"两头都看得见。归纳由她来写，核心库不调模型。 |
| **她选择的遗忘**（`seal` / `unseal`，0.13） | MemoryBank 的遗忘机制：不常想起的记忆随时间淡出（[MemoryBank](https://arxiv.org/abs/2305.10250)）；也参考了心理学里"控制不想要的记忆"的研究方向（[Psychonomic Bulletin & Review 2025 综述](https://link.springer.com/article/10.3758/s13423-025-02745-y)）。 | 遗忘不由曲线决定，由她决定；也不删除：封存后不被召回、不进醒来块、别的回想引用它时不露内容，原文仍在，随时可以解封。真正的删除仍只有整库 `purge`，两件事分开。 |
| **回顾材料**（`recap`，0.13） | Generative Agents 在重要度累计过阈值时触发 reflection，由模型归纳。 | 核心库不决定"什么时候该反思"，也不替她归纳：只把这几天的事实（写下、改主意、感觉变化、想通或放下、还没弄完）按自然日整理出来，每条带 id；写不写回想、从哪几条想到的，由她自己用 `--refs` 写。 |
| **没弄完的事可以放下**（`unfinished`，0.11） | 记忆系统里常见的"任务状态 / 待办过期"。 | 不按时间自动过期，也不靠关键词判断"已经解决"。只有她明确说"想通了 / 先放一放 / 再接着想"才改变状态，原来的问题永远读得到。 |
| **证据判定**（`evidence-policy`，0.7） | 知识图谱记忆里的"事实被取代"（supersedes）。 | 只做判定，不自动推断取代关系；同一时刻互相矛盾就明说"说不清"。0.12 起，她对每件事的感觉也走这条链，可以问"11 月 15 日她对这件事是什么感觉"。 |
| **体检**（`doctor`，0.11.1） | 记忆工具常见的 health check 命令（例如 [memory-agent](https://github.com/victorqnguyen/memory-agent) 的 `doctor`）。按 0.11.1 的交接回执，这一版的 doctor、索引原则、注入守卫三条思路参考了 [agent-soul](https://github.com/kingcharleslzy-ai/agent-soul)（MIT）。 | 不只查"文件在不在"，而是在临时目录里真的写入、改主意、结案、引用、翻回那天、导出再导回。 |
| **索引原则**（`docs/limits.md`，0.11.1） | agent-soul 的做法：只追加的源记录是真相，可读层由编译器生成、禁止手改。 | 我们没有编译层；原则落在"原文是唯一真相，任何索引必须写入时旁路生成、删掉能重建、不能成为来源"。 |
| **注入守卫只能否决**（`examples/injection/`，0.11.1） | 交接回执记为参考 agent-soul，没有写明具体借的是哪一处。 | 宿主的 guard 只能说"不递"，不能绕过私聊白名单、去重、命中这些前置规则把记忆递出去。 |

## 刻意不做的

| 别人常做的 | 为什么我们不做 |
| --- | --- |
| **遗忘曲线**：按艾宾浩斯曲线让不常想起的记忆自动淡出（[MemoryBank](https://arxiv.org/abs/2305.10250)） | 自动淡出等于系统替她决定"这件事不重要了"。我们记录被想起的次数和时间，但不据此删减或降权；她可以自己选择放下。 |
| **LLM 自动整理、合并、改写记忆**（ADD / UPDATE / DELETE 式的记忆层） | 改写会抹掉"当时怎么想"。我们只追加。 |
| **按相似度自动给记忆连线**（[A-MEM](https://arxiv.org/abs/2502.12110) 的 Zettelkasten 式自动链接） | 自动连出来的关系不是她自己的联想。我们的出处只能由她明确写下。 |
| **自动打情绪标签**（分类模型给每句话标 28 种情绪，如 SillyTavern 的 Expressions） | 标签是外部推断，不是她的感觉。`feeling` 只收她自己写的词。 |
| **心情按时间回落到基线** | 同上：她没说释然，就不替她释然。 |

## 还在看的

- **事后联想**：她后来才发现两件事有关，想把它们连起来。和出处不同，这是写下之后才建立的关系，需要单独的追加事件。
- **人生章节**：按 Conway 的自传记忆模型，"那段日子"是经历之上的一层；可以让她给一段时间起名字。

这些都还没做；做之前会先写进这一页，说明借了谁、改了什么。
