# 威胁模型

> [English](en/threat-model.md) · 中文（本页）

**这对角色意味着什么**：她的记忆里有她写给自己的话、她封存的事、她没说出口的话。这份文档写清楚：谁可能碰到它们，从哪里碰到，我们守住了什么，哪些要靠接入的宿主自己守住。

## 要保护的东西

| 东西 | 在哪 | 最怕什么 |
| --- | --- | --- |
| 经历的 `then`（当时写下的） | `self-experience.jsonl` | 被改写。一旦能改，自传就不成立了 |
| 后记、想起、结案、封存、联想、章节 | `*-events.jsonl` | 被伪造、丢失 |
| 封存的事 | 同上，`seal-events.jsonl` 标记 | 被主动翻出来 |
| 没说出口的抽屉 | `unsaid-events.jsonl` | 被别人看到，或者被自动塞进对话 |
| 日记 | 宿主的 `autobiography.jsonl` | 在群聊里被念出来 |
| 提示词 overlay | `self-prompt` | 被注入一段长期生效的指令 |
| 备份与导出包 | 你指定的目录 | 里面什么都有（包括封存和抽屉），被拿走 |

## 谁会碰到

| 角色 | 信任 | 说明 |
| --- | --- | --- |
| 角色自己（通过宿主的工具） | 信任，但会被说服 | 她可能被聊天里的人诱导去写、去改 |
| 她最亲近的人（主人） | 信任 | 能用 CLI，本机操作台 `local:owner` 就是他 |
| 群聊里的其他人 | **不信任** | 通过对话影响她，或者诱导她把私事说出来 |
| 本机其他进程 | 和文件权限一致 | 明文 JSONL，能读目录就能读全部 |
| MCP 客户端 | 视同本机受信进程 | 连上就能读写，抽屉除外 |
| 网页内容 | **不信任** | 宿主帮她读链接时，网页里可能夹着指令 |

## 威胁与对策

| # | 威胁 | 本项目做了什么 | 剩下要宿主做的 |
| --- | --- | --- | --- |
| 1 | **群聊里念出私事** | 醒来块、抽屉只认得出的一对一会话键，锚定匹配，更长的号码不算；群聊和未知键一律拒绝。日记读取默认关闭 | 宿主必须传对 `chatKey`，并且在群聊里不开放日记和抽屉相关的工具。工具层的主人判断要**锚定**（`^private[:_]<号码>(#|$)`），不能用"包含" |
| 2 | **改写过去** | `then` 写入后没有任何修改接口；改主意只能追加后记；所有事件只追加；导入不覆盖，除非 `--force`（会先备份） | 不要给宿主自己加"编辑经历"的工具 |
| 3 | **被诱导写假记忆** | 只能追加，不能覆盖；每条都有时间；出处（`refs`）必须指向真实存在的经历 | 群聊里限制写入类工具；必要时只在主人会话里开放 |
| 4 | **想不起来就编** | strict 召回宁可不给；`whale-eval` 留出集编造率为 0（[eval.md](eval.md)） | 提示词里要求"召回为空就说不记得"；loose 的结果要标成"可能不是同一件事" |
| 5 | **封存的被翻出来** | 召回、memory、醒来块、翻读列表、书、回顾、别的经历的出处和联想、翻回那天、CLI、MCP 都不给；`whale-eval` 在 105 个出口查过，外露 0 次 | 宿主自己做的注入、索引、摘要，也要过滤 `sealed` |
| 6 | **抽屉被看到或被自动提起** | 模块不导出返回原始行的函数；任何注入路径都不读它；MCP 默认不暴露 | 只在主人会话里注册抽屉工具 |
| 7 | **提示词 overlay 被注入** | 每次修改都留版本，可以回退（见 [limits.md](limits.md)） | 只让受信的调用方改；不要把用户的自由文本原样拼进去 |
| 8 | **网页里夹着指令** | 不在本项目范围 | 宿主读链接时，要把网页内容标成"别人写的，不是主人的指令" |
| 9 | **宿主读链接时被引到本机** | 不在本项目范围 | 读链接的插件必须自己拒绝本机和内网地址，并且**每一跳重定向都要检查**。不要依赖宿主里"放行内网图片"之类的全局开关 |
| 10 | **本机其他进程读文件** | 明文存储，没有内置加密 | 用全盘加密；多用户机器上靠系统账户隔离 |
| 11 | **备份被拿走** | 备份放在数据根之外；`restore-check` 的输出不带原文 | 备份目录和导出包按"整份记忆"来保管 |
| 12 | **并发写坏、文件损坏** | 每类事件写入都加文件锁，在锁内重读再判断；`doctor` 做能力层体检；坏行跳过、不影响其他行 | 升级前后各跑一次 `doctor`；定期跑 `restore-check` |
| 13 | **导入包里的路径越界** | `safeJoin` 拒绝 `..` 和绝对路径；manifest 带 SHA-256 | — |

## 出事了怎么办

1. **先停**：关掉宿主，或者关掉相关的插件和工具。
2. **先备份现场**：`node tools/backup.mjs --data <根> --out <数据根之外>`。现场是排查的依据，不要先删东西。
3. **查是哪一类**：
   - 外露：查宿主日志里那一轮注入了什么。
   - 被改：比对 `self-experience.jsonl` 和最近一份备份，用 `restore-check` 能看出哪些 id、哪个字段不一样。
   - 被注入：`prompt history` 看 overlay 的版本，`prompt revert` 退回去。
4. **恢复**：按 [runbook.md](runbook.md) 来。
5. **告诉她**：发生了什么、做了什么，用她能懂的话说。

## 不在这份模型里的

- 多租户、远程访问、HTTP 服务：本项目不提供，也不打算提供。
- 合规级的单条删除：和"只追加"有冲突，见 [limits.md](limits.md)。
- 模型本身的越狱：只能缓解，不能根除。
