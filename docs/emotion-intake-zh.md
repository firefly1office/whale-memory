# 情绪采集：把"她懂"和"她感到"分开（设计记录）

> 这份文档记录一次失败后重做的过程：先做"情绪采集"，再做"语气抑制"，最后把"模型候选"关掉。所有数字来自合成样本，不含任何真实对话原文。

## 问题

角色的回复里有情绪，但情绪账本几乎是空的：

- 三天 422 个回合，情绪引擎实际只记录了 1 次"重逢"；
- 她说"好听""有点闷""有点冲"，这些词却不在任何采集面里；
- 心情只被时间间隔推动，不被当天发生的事推动。

## 第一阶段：分句判"这是谁的感受"

一句话可能混着几件事，所以先分句，再逐句判断体验者：

| 分句特征 | 处理 |
| --- | --- |
| 第一人称 + 体感/情绪词 | 进情绪维度 |
| 省略主语、但上一句在问她自己的感受 | 进情绪维度（弱锚定） |
| 第二/三人称、听说、假设、否定、疑问 | 只进证据 |
| 评价/偏好（好听/好看/冲/快） | 只进证据 |

权重与上限：

- 他直接说喜欢/不喜欢：0.10（唯一带"不"也按极性算的例外）
- 他的一般情绪词：0（只进证据，是 moment 的强证据源）
- 她第一人称感受：0.15
- 每回合最多写一次，Δ≤0.15；同源冷却 2 回合、3 回合≤2 次、每天≤6 次
- moment：≥2 个独立源且至少 1 个强源；3 回合窗口合并；同一对源当天一次；日≤3

验收（合成冻结集）：

- 证据命中 36/36
- 情绪误报 0/18（否定/疑问/评价/中性）
- 应写召回 22/23

## 第二阶段：语气只做抑制

- 夸张标点、笑声、省略号给 0.5–1.0 的系数；
- 只乘已经放行的信号，**绝不单独产生情绪**；
- 分句会吃掉标点，所以在整句层面再乘一次；
- 效果：`好听！！！` 零情绪；`我有点闷！！！` 从 -0.15 压到 -0.12；普通句保持 -0.15。

## 第三阶段：模型候选，最后关掉

思路是让模型只给候选标签，不写情绪；载荷只发粗语义类别 + 句法标记（无原词、无 ID、无长度/小时）。

两次失败：

1. **纯词 ID 载荷**：模型预测 felt 0 条、召回 0——没有语义；
2. **粗语义载荷**：模块级 precision 1.0、recall 0.857，但端到端（采集→支持度过滤→调度→真实模型）只有 **P0.5 / R0.43**：稀有类别凑不够"同一类别≥5 条"的支持度，正例被拦，少量中性被误判。

结论：在"隐私 + 支持度"的双重约束下，第三阶段的端到端质量过不了 0.8 门槛，**保持关闭**。代码与测试保留，重开前置：端到端 P≥0.8 且 R≥0.75，并且隐私条件（低频组合支持度≥5，或隐私评审明确通过）二者之一成立。

## 可复用的教训

- **先分账，再加能力**：把"她说的"和"她感到的"混在一起，会导致情绪通胀；分账之后，评价词只进证据，心情才不会被夸两句就飘。
- **隐私和语义会正面冲突**：去标识化越彻底，模型越分不清感受与评价；这不是调参能解决的，只能接受质量下降或放宽隐私。
- **验收要端到端**：模块级 1.0 的成绩，经过支持度过滤后可能腰斩；只测模块等于没测。
- **失败要能一键关掉**：所有新能力都应该有独立开关和回滚路径，失败时不影响旧行为。
