# 这套东西是怎么来的

> [English](en/related-work.md) · 中文（本页）

分三类说，不混在一起：**真正采用的外部东西**、**事后对照但明确没抄的**、**自己独立形成的**。

设计想法是作者自己想出来的——起点是"她老是忘事"这个具体问题，不是某篇论文。写代码和论文的是几个 AI Agent，他们在过程中查过别人的工作；能追溯到的引用列在下面并标明用在哪，追溯不到的部分不声称不存在。

## 一、真正采用的外部东西（少）

| 来源 | 借的是什么 | 用在哪 |
| --- | --- | --- |
| 事件溯源（Martin Fowler 一类范式） | 状态变化存成事件，读取时重放 | `later` / `recall` / `seal` / `unsaid` 等事件文件；`asOf` 的时间线重建 |
| OCC 评价模型 + PAD 心情 | 合意性、意外度、归因、可控性 → 情绪；愉悦 / 唤醒 / 掌控三维 | 宿主侧的情感层（`psyche`） |
| 双时态 / 时间线（Zep 一类） | "事情何时为真"和"系统何时知道"分开 | 事后对照；我们答的是"那时的她怎么想"，不是"那时什么为真" |
| MCP / JSON-RPC | 协议与 stdio 传输 | MCP 适配器 |
| 评测基准里的"拒答" | 信息不存在时要能返回空 | LoCoMo / LongMemEval 的指标口径；`recall` 的 cover 门 |
| Wilson / Clopper–Pearson | 比例的置信区间 | 论文里的区间估计 |

这些是**通用范式、理论、协议**，不是别人的实现。

## 二、事后对照、明确没抄的

先做出来，后来才读到；读到之后也没有改实现去迁就它们。

| 相近工作 | 它怎么做 | 我们明确不照做的地方 |
| --- | --- | --- |
| Generative Agents 的记忆流与反思 | 观察入流，重要度过阈值自动归纳成反思 | 不自动归纳；只取"出处必须真实"，`--refs` 指向的经历必须存在 |
| MemoryBank 的遗忘曲线 | 不常想起的记忆按艾宾浩斯淡出 | 不自动淡出；封不封由她决定，封存也不删除 |
| A-MEM 的自动链接 | 模型按语义自动建链、自动更新 | 链接必须她亲手连，并且必须写理由 |
| Mem0 的增删改 | ADD / UPDATE / DELETE 式记忆层 | 只追加，绝不改 `then` |
| MemGPT 的上下文编辑 | 模型自己整理、改写记忆正文 | 不让模型改正文；只有她能追加后记 |
| Conway 的人生时期 | 记忆按层级组织，"人生时期"在最上层 | 不自动切章节；名字由她起，改名留旧名 |

## 三、独立形成的

这几条是骨架，先于任何外部资料：

- **`then` 不可改，`later` 只追加**——旧看法不被新看法覆盖
- **找不到就说找不到**——检索为空能返回空，不编（开发集与留出集的编造率都是 0）
- **封存不是删除**——不被召回、不进醒来块，原文还在，随时解封
- **抽屉永不自动注入**——没说出口的话只有她自己打开时看得到
- **细节召回只给原文与证据状态**——supported / related / ambiguous / unmatched，不补没写过的细节
- **什么值得记、要不要放下，由她决定**——系统不替她判断重要度，也不按时间自动过期

## 刻意不做的

| 别人常做的 | 为什么我们不做 |
| --- | --- |
| 遗忘曲线自动淡出 | 自动淡出等于系统替她决定"这件事不重要了" |
| LLM 自动整理、合并、改写记忆 | 改写会抹掉"当时怎么想" |
| 按相似度自动连线 | 自动连出来的关系不是她自己的联想 |
| 自动打情绪标签 | 标签是外部推断，不是她的感觉；`feeling` 只收她自己写的词 |
| 心情按时间回落到基线 | 她没说释然，就不替她释然 |
