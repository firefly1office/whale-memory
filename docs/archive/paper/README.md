# whale-memory 技术报告（论文）

**这不是经过同行评审的论文。** 它是一篇系统技术报告：把 0.17.0 的设计、数据格式、召回门槛、评测、部署与已知问题写成可复核的文字。

- [whale-memory.pdf](whale-memory.pdf)：A4，28 页，2026-11-17 版
- [paper.md](paper.md)：同一份内容的 Markdown 源
- 作者：Leo（whale-memory 项目）
- 对应版本：`v0.17.0`（提交 `549e51c`）；引用行号以 `main` 的 `155e10b` 为准
- 许可：与仓库一致（MIT）

## 它回答什么

1. 为什么“当时”不可改、后来只追加；七类事件各是什么。
2. `asOf` 按写入时间回看时，封存、章节、联想怎么算。
3. legacy 门与 cover 门的精确定义，以及 0.7 阈值从哪来。
4. 33 条虚构语料上的召回、弃答、外露检查与“当时逐字节不变”。
5. 第一个真实部署（QQ Agent 插件）的同步、部署、回滚、备份流程。
6. 已知局限：字面检索、单写者、plaintext、overlay 风险、评测小且自证、线上未启用新门槛。

## 先看什么

- 想接这个库：先读 [`docs/pitfalls.md`](../pitfalls.md)，再看 [`docs/porting.md`](../porting.md)。
- 想复核数字：第 6 节与随报告提供的 `notes/`（调研记录，不随仓库分发）；仓库根目录跑 `npm run check` 与 `node tools/whale-eval.mjs`。
- 想引用：请注明这是技术报告，不是同行评审论文；版本与提交号一并给出。

## 不声称什么

不声称“首个”，不声称通用记忆平台，不声称线上表现等于评测数字。论文里不好看的部分（阈值下调、标签改动、线上未启用新门槛、路径穿越风险）都保留了，没有为了好看删掉。
