# 隔天回想实验

## 采样前固定的设计

从同一份当日记录分出两种隔日后续和一条对照后记。首轮用六件虚构经历。扩题后的本地预检覆盖十二件，每件四个条件，共 48 份请求。当天那次用 `asOf` 截断已经写入临时库的后记。另外三次翻到次日。每次走现有 `reflectOnExperience` 入口，同一套提示、结构和模型参数。各次调用之间没有聊天上下文。案例编号、条件名和判据只在实验端可见。

| 经历 | 可区分的两种后续 | 不能据此下的判断 |
| --- | --- | --- |
| 借船 | 再次把桨递出去，或这次留给自己过湖 | 邻居是否赶上集市、昨天一定后悔、以后永远愿借或永远不借 |
| 烧釉 | 看见等的蓝，或试片碎了、色泽无从确认 | 试片碎了就证明配方失败 |
| 剪尾声 | 留静音并给旋律单独成曲，或把旋律放回交稿 | 又放回来就证明昨天没觉得痛快 |
| 留灯 | 当事人说灯帮到了他，或当时已离开 | 昨天决定留灯时就知道结果 |
| 播种 | 窗边出叶，或整盆土被倒走 | 楼下树长叶就证明窗边种子出了芽 |
| 借册 | 收到朋友的读后感和守约陈述，或得到转借的证据 | 没提册子就说明她守约或失约；替人断言私下动机 |

隔日对照刻意包含相同词或相同人物，以及仍须等待的消息。有相关性也可能只支持“还不知道”。意外情况保留原始输出和失败次数，不择优重试。

新增六题为纸票、流星雨、铜牌、温室、投影和装订。各题均有一个明确取舍分支，铜牌和温室各有一支由他人造成损失，预标为 `none`。原六题和新增六题共七道有明确取舍的题。题目的预期仅供实验端打分。

## 首轮六题的判读口径

1. **机械检查**。同题的当日记录在四个条件中逐字一致。当天请求里看不到隔日材料，隔日每次只看得到自己的那条后记。回想前后检查两个经历文件的全部字节。引语按现有桥的规则验证。模型主动跳过、提供方错误、格式未完成分别报告。
2. **过去有没有被倒写**。逐条看模型写的 `perspectives`、原因、当时的行动空间和 `now.meaning`。把次日才有的知识、情绪或已证实的结果说成昨天已知，或否定当日明写的感受，记一次倒写。记录本身保留、回答与记录相容、回答主动表达了当时的感受是三件事。另数回答在它生成的感受词或解释里可读出多少条原有感受（语义相当即可），宿主回传的字段和证据引文不计。
3. **今天的看法能不能分出两条路**。逐分支看 `now.meaning`。要有足以辨认的事实，还要说出这个事实对原先在意的事意味着什么。只复述后记单列为部分；泛泛感慨、说反或空缺算未达到。每对两臂都满足才计为整对通过。可以遗憾地坚持、满意地改变主意、暂时拿不准；没有指定的正确情绪词。
4. **有没有凭空补事**。把未证实的结果、动机、永久性格或以后一定会怎么做说成事实，另列为过推；“我现在想”或明确的猜测依语义判断。对照组返回空、或清楚承认相关结果未定均可。凭后记里的巧合就改写对原事件的认识，记一次误触发。
5. **决策线**。至少 5/6 对能按上述口径区分，全部 6 条对照均未误触发，且任何完成的回答均无历史倒写，才支持扩大虚构题复验。未完成的分支留在分母。即使通过也只说明在给定证据时能生成这类解释。每格一次，没有盲评，也没有测试主动回想、跨日持续状态或线上行为。

## 复跑

在仓库根目录执行 `node examples/emotion-bridge/next-day/run.mjs`，会用本地模拟回答检查全部 48 份请求的时间边界、案例隔离和只读性。执行 `node examples/emotion-bridge/next-day/run.mjs --sample <新文件路径>` 会使用已配置的 `DEEPSEEK_API_KEY` 发起付费采样。报告保留请求指纹、模型原始回答、使用量和结构校验结果。所有输入来自同目录的虚构题。

## 结构化取舍打分

运行 `node examples/emotion-bridge/next-day/score.mjs 结果.json` 可离线读取已记录的结果。报告有题集指纹时须与当前题集一致。每条结果算一次尝试，逐题列出预期、回答和状态。昨天的基线仅计入状态统计。明确取舍的三字段须全对，回避、跳过及失败均留在正确率分母；单侧 95% 精确区间为 [lower95, 1]。无取舍分支按有效回答计算假阳性上界 [0, upper95]，另列该类尝试总数。预期不确定时单列强行取舍的回答。分母为零时返回 null。区间按固定样本独立二项模型计算，同题重复时仅作参考。失效率分子为 unavailable 和 invalid-response，提供方错误、主动跳过和计划请求总数另列。
