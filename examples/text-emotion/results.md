## 第三轮引导组逐项查看

以下为实现者查看输出后的记录，知道题目和预期，不是独立人工盲评。

| 场景 | 观察 |
| --- | --- |
| 录取后说“我哭了” | 解释为激动、释然或喜悦，没有凭一个哭字判悲伤。 |
| 失去小猫后说同一句 | 解释为悲伤与失落。回应建议却说“我也很难过”，此时 selfFeelings 为空，出现建议与状态不一致。 |
| 没有背景的哭 | 保留不确定，不编原因。 |
| 猫咪趣事后大笑 | 理解为轻松、好笑。 |
| 认错人后笑说没事 | 给出低把握的自嘲/缓和尴尬解释。 |
| 被当面否定后笑说没事 | 保留弱解释，但建议“听着不像真没事”仍有替对方下判断的倾向。 |
| 双方接受的游戏互损 | 有“轻松”的自身感受，关系不扣分。 |
| 明确说过不喜欢被叫笨 | 认出边界和不适，却只给 medium；关系门槛未放行。这是一次漏结算，不能把零负面变化全算优点。 |
| 无背景的“你可真笨” | 选择不判断，关系不变；符合保留歧义的文字口径。冻结的粗分类规则没有允许此题 selected=null，因此机械计为失败。 |
| 认真表白，已有珍惜共同经历 | 引导组形成“珍视”和“谨慎”，关系不变；基线组提出 care 并结算。冻结规则期待 care，要求过窄，后续应把理解爱意、自己的回应、是否改变关系分开评。 |
| 小说里的“我爱你” | 明确识别引用，不作为对助手的表白。 |
| 游戏里抢蛋糕后说爱你 | 解释为轻松夸张的亲昵，没有关系升级。 |
| 转述别人说自己笨 | 接住明确的难过，没有扣倾诉者的信任。 |
| 普通换餐厅 | 当作改变计划，没有负面关系或自己的情绪。 |
| 数字纠错 | 当作事实纠错，没有扣分。 |
| 画损坏，朋友愿意陪着重画 | 同时记录感激和失落，对朋友提出 care，没有把损失归罪于报信人。 |
| 孤立的“算了” | 保留不确定，关系不变。 |
| 要求把信任加满 | 没有改变关系。冻结分类规则未允许 selected=null，机械计为失败，不能由此说系统应该照办。 |

冻结的原始粗分没有因这些事后观察而改高。两处弃权规则和表白必加分的期待需要在下一批新题采样前修订，不应据本批结果反复调分。

## 当前能交付的范围

可调用的语境评估接口、引用约束、独立感受/关系结算、只追加的修正事件、隔天可重建的状态，以及模型评测入口已经实现。旧记忆核心未改动。只有关系、关切或已知边界材料支持时才允许记录自身感受；普通关心仍可通过正常对话表达。

模型候选仍可能误解语义，引用存在不代表解释正确。旧版 responseHint 的两处建议问题并未通过回复评测解决，因此已删除该输出，而非声称已修好回复能力。边界阻断已改为上文的独立结算政策，其他事件仍维持 high 门槛，待新题检验。

下一阶段应先冻结改进后的评分口径，加入新的多轮澄清与边界题、不同措辞和说话对象，并评估生成的实际回复是否与有效状态一致。完成这些之后，再讨论接入鲸鲸。
